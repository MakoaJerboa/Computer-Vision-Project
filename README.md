# Computer Vision Project: 3D Spring Pendulum Analysis

This project uses MATLAB and computer vision techniques to analyze the motion of a spring pendulum system in 3D. Principal Component Analysis (PCA) is applied to visualise the system's principal components.

## Features

- 3D motion tracking of a spring pendulum
- Computer vision-based data extraction
- Automatic PCA analysis and visualisation

## Requirements

- MATLAB
- Image Processing Toolbox

## Usage

1. Clone the repository.
2. Run the MATLAB script to automatically process video/images, extract motion data, apply PCA, and display the principal component graph.
3. Save the graph from the MATLAB pop-up for your own use.
